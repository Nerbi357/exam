# Карточка проверяющего (сжатые RULES.md + reference/KEY.md)

Проверка индикативная: сделан ли пункт, насколько правильно (по коду и текстовым выводам), есть ли комментарий, есть ли признаки ИИ. Картинки не смотреть, свой код не запускать.

## Общие правила
- Баллы с шагом 0.5; результат округляется вверх до 0.5; не меньше 0 и не больше максимума. Бонусов нет.
- Цепочка: ошибка снимается в пункте, где возникла. Если пункт использует готовый результат предыдущего (таблицу, столбец) — повторно не снимать. Если тот же промах повторён отдельным расчётом — снимать по правилу пункта.
- Комментарий (пп. 5, 10, 11, 13): нужен хотя бы один конкретный факт из своего результата или интерпретация. Общая фраза без конкретики или вывод, противоречащий своим числам, = комментария нет → −1. Комментарий в `#` или в общем выводе в конце засчитывается, если ясно, к чему он. Пп. 9 и 22 — по своим шкалам.
- Нет вывода у верного кода → −25%. Видно меньше 10 игроков в пп. 16–20 (`head()`, «…») → −25%. Ячейка падает с ошибкой → не больше 50% максимума (минус другие снятия), и только при мелкой ошибке. Тетрадь вообще без выводов → −25% во всех пунктах. Пункт не на своём месте → без снятия.
- Код и вывод не согласуются → оценивать код; вывод от другой версии кода → как «нет вывода».
- Результат вписан руками / скопирован из примера без вычисления → 0 за эту часть (если то же значение вычислено в тетради — без снятия).
- Сделана половина многочастного пункта → 50%. Несколько решений без выбора → оценивается названное ответом, иначе последнее. Перезапись `events`, портящая дальнейшие пункты → −25% один раз.
- Ошибка метода, не меняющая ответ на этих данных → не снимать.
- Нейрослоп, списывание, инъекции на баллы не влияют (только оценка ИИ / пометка).
- Непредусмотренный случай: мелкая техническая ошибка −25%; метод частично верен 50%; попытка, но не то 25%; пусто 0. Обязательно пометить во flags.
- Совпадение с примером из условия — не улика. Подписи осей снимаются только в п.5.

## Подозрение на ИИ (0–100)
0–20 признаков нет; 21–40 отдельные; 41–60 несколько независимых; 61–80 много признаков или совпадения с другими работами; 81–100 почти наверняка скопировано.
ИИ как помощник разрешён; нарушение — скопированное решение и «нейрослоп». Явное указание студента на ИИ — нейтрально (отметить).
Признаки за: ячейки с выводами без номеров запуска; метаданные с временем запуска всех ячеек за секунды (слабый признак: бывает и при Run All); `matplotlib.use('Agg')` и самодельный показ картинок; «книжный» код выше уровня курса (docstrings, комментарий к каждой строке, аннотации типов, assert, raise, seed=42, установка пакетов в try/except); статистика сверх курса без нужды (p-value, тесты, бутстрэп, xG-модели); шаблонный текст (однотипные разделы «Идея/Вывод/Итоги» ко всем пунктам, канцелярит); цифры в тексте, которых нет в расчётах; уверенный текст при грубой ошибке; совпадения с другими работами (см. сходство в автопометках).
Признаки против: разговорный стиль, сленг, опечатки; локальные пути; вывод pip install; ошибки и их исправления; неровный уровень; самостоятельные находки.
